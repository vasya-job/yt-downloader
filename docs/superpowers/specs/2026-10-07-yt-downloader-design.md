# YouTube Загрузчик: дизайн

Дата: 2026-10-07. Платформа: только macOS.

## Цель

Однооконная программа-обёртка над yt-dlp. Пользователь вставляет ссылку, выбирает аудио или видео, формат, параметры и папку, нажимает «Скачать» и видит прогресс в том же окне. Мастеров, вкладок и отдельных экранов настроек нет.

## Критерии приёмки (из ТЗ)

- Одно окно, без мастеров и вкладок.
- Можно скачать только аудио в mp3 в выбранную папку с заданным именем.
- Можно скачать видео с потолком 1080p.
- Путь сохранения переживает перезапуск.
- Повторный запуск с той же ссылкой не затирает файл молча.
- Интерфейс не зависает на время скачивания.
- Логика вызова yt-dlp отделена от окна и проверяется без GUI.

## Стек и подход

- Python + PySide6.
- Ядро на чистом Python запускает yt-dlp через `subprocess` и сообщает о событиях колбэками. Окно оборачивает ядро в `QThread`.
- Проверить на первом шаге: поддерживает ли PySide6 Python 3.14. Если нет, использовать venv на Python 3.13 (Homebrew).
- Сейчас в системе есть `yt-dlp` и `ffmpeg` (`/opt/homebrew/bin`), нет Tkinter, CustomTkinter и PySide6.

## Структура

```
ytgui/
  core/
    options.py    # DownloadOptions (dataclass) и валидация
    command.py    # build_command(options) -> list[str], чистая функция
    progress.py   # разбор строк stdout -> ProgressEvent
    errors.py     # stderr -> понятный текст
    runner.py     # DownloadJob: subprocess, колбэки, cancel()
    paths.py      # поиск yt-dlp/ffmpeg, уникальное имя файла
    settings.py   # JSON в ~/Library/Application Support/
  ui/main_window.py
  __main__.py
tests/
packaging/build_app.sh   # PyInstaller -> .app с yt-dlp и ffmpeg
```

Ядро не импортирует Qt.

## Окно

Фиксированная ширина около 680 px, высота по содержимому. Блоки сверху вниз:

1. **Ссылка.** Одно поле: ролик, шортс, плейлист.
2. **Что скачать.** Радио «Видео» / «Только аудио» и чекбокс «Скачать весь плейлист». Чекбокс активен, только если ссылка похожа на плейлист (`list=` или `/playlist`).
3. **Формат.**
   - Аудио: MP3, M4A, OPUS, WAV.
   - Видео: MP4, MKV, WebM и потолок качества: лучшее, 1080p, 720p, 480p.
4. **Параметры.**
   - Слайдер качества аудио 0-9 (0 = лучшее); для WAV отключён.
   - Шаблон имени, по умолчанию `%(title)s.%(ext)s`.
   - Браузер для cookies: нет / Chrome / Firefox / Edge.
5. **Куда сохранить.** Поле пути, кнопка «Обзор», чекбокс «Открыть папку после загрузки».
6. **Действия.** «Скачать» и «Отмена», полоса прогресса, строка статуса («12,4 МБ из 20,0 МБ (1,8 МБ/с)»), короткий лог.

«Скачать» неактивна, пока ссылка пустая или папка не выбрана. Во время загрузки все поля неактивны, «Отмена» активна. Папка создаётся, если её нет.

Макеты (стиль, слайдер, чекбокс, строка прогресса, лог) служат ориентиром; при расхождениях приоритет у ТЗ.

## Команды yt-dlp

- Аудио: `-x --audio-format F --audio-quality N -P <папка> -o <шаблон> <url>`.
- Видео: `-f "bv*[height<=H]+ba/b[height<=H]" --merge-output-format F`. Для WebM селектор жёстче (`[ext=webm]`), иначе слияние падает. Без ограничения «лучшее» условие по высоте опускается.
- Плейлист: те же флаги, в шаблон добавляется `%(playlist_index)s`. Чекбокс включён: `--yes-playlist`; выключен: `--no-playlist`.
- Cookies: `--cookies-from-browser <браузер>`.
- Прогресс: `--newline --progress-template` с разбираемой строкой. Для плейлистов разбирается «item N of M». Строки постобработки (`[ExtractAudio]`, `[Merger]`) дают статус «Конвертация…».

## Повторное скачивание

- Одно видео: до запуска определяется итоговое имя (`--print filename` и выбранное расширение). Если файл есть, к имени добавляется ` (1)`, ` (2)` и так далее.
- Плейлист: `--no-overwrites`; существующие файлы пропускаются, в лог пишется количество пропущенных. Суффикс для каждого элемента не делается.

## Ошибки

- ffmpeg проверяется до запуска. Он нужен для любого `-x` (включая M4A и OPUS) и для слияния видео. Если его нет, показывается сообщение, а не падение.
- `ERROR:` из yt-dlp переводится в короткую фразу: бот, приватное видео, возрастное ограничение, недоступно, сеть. Остальное показывается последней строкой `ERROR:` без трейсбека. Полный вывод остаётся в логе.
- «Отмена»: SIGTERM, через 3 секунды SIGKILL. Файлы `.part` остаются, чтобы можно было докачать.

## Настройки

JSON в `~/Library/Application Support/YT Загрузчик/settings.json`: папка, режим, формат, качество, шаблон, браузер cookies, «открыть папку». Папка по умолчанию пустая, пока пользователь её не выберет.

## Проверка

- pytest на чистые части: `build_command`, парсер прогресса, маппинг ошибок, уникальное имя, настройки.
- `runner` проверяется на подставном скрипте вместо yt-dlp: успех, ошибка, отмена.
- Дымовой тест окна с `QT_QPA_PLATFORM=offscreen`.
- Один реальный запуск с короткой ссылкой (сеть); файлы в scratchpad, не в проекте.

## Упаковка

Последний шаг: `.app` через PyInstaller. Внутри `yt-dlp_macos` и статический ffmpeg (скачиваются скриптом). Поиск бинарников: сначала рядом с приложением, затем `PATH` и `/opt/homebrew/bin`. Ffmpeg из Homebrew для переноса не годится из-за динамических библиотек.
