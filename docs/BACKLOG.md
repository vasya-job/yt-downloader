### Отложенные замечания ревью (все малые)
- [ ] `DownloadOptions.validate()` не проверяет тип `audio_quality` (bool, float, None); тесты без `match=` и без граничных значений.
- [ ] `unique_stem`: гонка «проверил и занял» (для одного пользователя допустимо); для плейлистов существующие файлы только пропускаются, коллизия аудио с промежуточным файлом другого расширения по элементам не обрабатывается.
- [ ] `format_bytes` на `nan` и `inf`; `explain(["ERROR:"])` даёт пустую строку; `strerror` ОС по-английски внутри русского сообщения.
- [ ] Runner: `_tail` не сбрасывается между запусками; финальный `kill` группы пропускается, если лидер уже собран и колбэк упал (маловероятно с настоящим yt-dlp); `proc.wait()` выполняется под замком.
- [ ] Окно: «Отмена…» перезатирается поздними событиями прогресса; высоту можно растянуть вручную; тест несохраняемых настроек не проверяет запись в лог.
- [ ] e2e: видео для проверки «недоступно» может стать доступным (тогда тест пропускается); тест отмены без `try/finally`; нет пропуска, если нет `ffprobe`.
